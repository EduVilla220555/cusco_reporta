# Santiago Reporta - Plataforma de Reportes Urbanos

## Estructura del Proyecto

- **backend/**: Servidor Node.js con Express
- **frontend/**: Aplicacion React con Vite
- **database/**: Scripts SQL para la base de datos

## Instalacion

### Backend
```bash
cd backend
npm install
```

### Frontend
```bash
cd frontend
npm install
```

## Configuracion

1. Copiar .env.example a .env en backend y frontend
2. Configurar credenciales de MySQL
3. Ejecutar scripts de base de datos

## Ejecucion

### Backend
```bash
cd backend
npm run dev
```

### Frontend
```bash
cd frontend
npm run dev
```
